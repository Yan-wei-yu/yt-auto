# 韭菜週報：經營策略

## 一句話定位

一根每週都被割、每週都長回來的韭菜「阿韭」，每週日帶你看完一週美股，最後用「本週時事概念股」吐槽時事。

![阿韭角色設定](character_sheet.png)

| 決定 | 原因 |
|---|---|
| **美股為主** | 台灣用複委託、海外券商買美股的人很多；財經內容的廣告單價也比較高。 |
| **散戶視角，不當老師** | 「韭菜」是自嘲，觀眾有共鳴；不報明牌，法規風險也低。 |
| **每週一支長片** | 長片才能累積觀看時數（申請廣告分潤的主要門檻），一週一次也做得完。 |
| **從長片剪 3 支 Shorts** | Shorts 負責吸引新觀眾，再導回長片。 |
| **本週時事概念股** | 把當週新聞做成虛構的 K 線，最有話題性、最容易被分享。 |

## 第 0 週：頻道改造（這些要你親自做）

1. **改頻道名稱**：預設「韭菜週報」。其他候選：「阿韭看美股」、「韭是要賺」。
2. **改 handle**：`@Mander_kun` 跟新內容無關。到 YouTube Studio → 自訂 → 基本資訊，挑一個還沒被用掉的，例如 `@LeekWeekly`、`@JiuCaiWeekly`。
3. **舊的小火龍影片設成私人或刪除**，避免被版權警告，也跟新定位不合。
4. **頭像**：上傳 [`avatar.png`](avatar.png)。
5. **頻道說明**（直接貼上）：
   ```
   我是阿韭，一根每週都被割、每週都長回來的韭菜。
   每週日 20:00，用散戶的角度帶你看完一週美股：大盤、財報、Fed，再加一檔「本週時事概念股」。
   我們是散戶，不是老師：不報明牌、不喊進出場。內容僅供參考與娛樂，不構成投資建議。
   ```
6. **驗證電話**（Studio → 設定 → 頻道 → 功能資格）：驗證後才能上傳自訂縮圖。週報很吃縮圖，這步一定要做。
7. **Google 帳號開兩步驟驗證**（YPP 必要條件）。
8. **建立播放清單**：「韭菜週報」、「本週時事概念股」。

## 每週流程

| 時間（台灣） | 誰 | 做什麼 |
|---|---|---|
| 週六上午（美股週五收盤後） | Claude | 整理一週新聞、抓行情、寫好 `weeks/<週>/episode.yaml` 和 `market.json` |
| 週六 | 你 | 審稿：事實、語氣、有沒有你想加的梗 |
| 週六 | 你 | 錄音（約 11 段、總長 5–6 分鐘，大約 20 分鐘錄完），或先用 TTS 預覽 |
| 週六晚 | 程式 | `python -m yt_auto build`：長片＋3 支 Shorts＋縮圖＋上傳清單 |
| 週六晚 | 你 | 照 `upload.md` 上傳並排程：長片**週日 20:00**，Shorts **週一、三、五 20:00** |
| 週一 | 你 | `python -m yt_auto stats`，看留存和點閱率，決定下週要改什麼 |

## 紅線

- **不報明牌**：不說買、賣、目標價、進場點，只講新聞、數據和阿韭的反應。在台灣，沒有投顧執照公開推薦個股可能違法。程式會在旁白出現這類字眼時警告。
- **概念股一定標「虛構」**：畫面有「虛構・純屬娛樂」章，旁白沒講「虛構」程式直接擋。
- **數字要有出處**：週漲跌用收盤價計算；只有單一來源的說法寫「據報導」。
- **不拿災難、傷亡、個人隱私開玩笑**；政治題材兩邊都可以酸，但不站隊。
- **不用別人的新聞畫面或影片片段**（版權），圖表都自己畫。
- **配樂**只用 YouTube 音效庫。

## 配音

- **最推薦自己錄**：每段一個檔，放在 `weeks/<週>/voice/s01.m4a`、`s02.m4a`…，程式自動接上。YouTube 打擊的是「大量產出、AI 唸稿」的頻道，真人聲音最安全，也最容易建立信任。
- **edge-tts 預覽**：免費、自動，但它是微軟 Edge 朗讀服務的非官方用法，商用條款不明確。只拿來預覽節奏，正式上片前換成自己的聲音，或改用有商用授權的 TTS。

## 收益路線圖

| 階段 | 門檻 | 收入 |
|---|---|---|
| 0–3 個月 | 每週 1 長片＋3 Shorts，先做滿 12 集，找出最有效的標題和縮圖 | 還沒有 |
| 粉絲贊助層 | 500 訂閱＋90 天內 3 支公開影片＋12 個月 3,000 小時長片觀看 | 頻道會員、Super Thanks |
| 廣告分潤 | 2027/2/1 起的新申請者：1,000 訂閱＋12 個月 **8,000 小時**長片觀看 | 廣告分潤 |

說實話：8,000 小時不容易。如果一支長片 5.5 分鐘、觀眾平均看一半，一年需要大約 17.5 萬次長片觀看，相當於每週 3,400 次左右。所以：

- **縮圖和標題是成敗關鍵**：每週都試不同寫法，看點閱率。
- **YPP 以外的收入**：阿韭的「被割」系列表情很適合做 LINE 貼圖；有穩定觀看後可以接理財 App、券商業配（業配要標示，也一樣不能變成推薦個股）。

## 每支影片的品質檢查

- 前 15 秒講出本週最大的事，而且要有一個數字（例如「那斯達克一週 -4.5%」）。
- 每段 20–40 秒，每段畫面都不一樣。
- 縮圖：兩行大字（指數＋漲跌幅）＋阿韭表情，縮到手機大小還看得清楚。
- 標題：數字＋反差（例如「財報好卻跌 9%」）。
- 結尾問一個好回答的問題（「你這週被割了幾趴？」），留言數會影響推薦。
